# Doomscroll

Doodle Jump по нескінченній стрічці X. Гра запускається прямо з поста через картку типу `player`, так само як Tweety Flap.

## Що всередині

- `server.js` — маленький сервер на Node без залежностей. Віддає гру на `/` і `/embed`.
- `public/game.html` — сама гра з мета-тегами для X (`twitter:card=player`, `twitter:player` → `/embed`, 800×800).
- `public/og.png` — прев'ю картки 1200×1200.
- `public/press-start-2p.woff2` — піксельний шрифт, тому сторонні сервіси не потрібні.

Адреси в мета-тегах підставляються автоматично з домену, на якому працює сервер, тож нічого правити не треба.

## Деплой на Railway

1. Створи новий репозиторій на GitHub і завантаж туди вміст цієї папки.
2. На railway.app натисни New Project → Deploy from GitHub repo і вибери цей репозиторій. Railway сам побачить `package.json` і запустить `npm start`.
3. Відкрий сервіс, далі Settings → Networking → Generate Domain. Вийде адреса на кшталт `doomscroll-production.up.railway.app`.
4. Відкрий цю адресу в браузері й перевір, що гра запускається.

Варіант без GitHub: встанови Railway CLI, у цій папці виконай `railway login`, `railway init`, `railway up`, а потім згенеруй домен у налаштуваннях.

## Публікація в X

Встав адресу в пост останнім рядком, як у Tweety Flap. X підтягне картку з прев'ю, і гра відкриється в один тап.

Якщо картка не з'явилась одразу, X міг закешувати сторінку без тегів. Зачекай кілька хвилин і створи пост заново.

Свій домен можна задати змінною `PUBLIC_URL` (наприклад `https://doomscroll.fun`), інакше береться домен із запиту.
